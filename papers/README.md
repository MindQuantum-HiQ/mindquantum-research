# 论文复现（Paper Reproductions）

本目录存放基于 MindQuantum 的论文复现项目。每个复现项目占用一个独立子目录，命名规范为：

```
papers/<年份>_<论文简称>/
```

例如：`papers/2024_adapt_qaoa/`。

新增项目后请在上表追加一行。

## 提交要求

1. 复制 [`_template/`](_template/) 作为项目骨架，按模板补全 `README.md`。
2. 提供 `requirements.txt`，注明 `mindquantum` 及关键依赖的版本。
3. README 中给出原论文的 arXiv / DOI 链接，以及复现结果与原文结果的对比（图或表）。
4. 涉及随机性的实验请固定随机种子，保证结果可复现。
5. 完整流程与通用要求见仓库根目录的 [CONTRIBUTING.md](../CONTRIBUTING.md)。
