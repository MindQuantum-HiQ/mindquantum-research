# 量子计算黑客松

本目录存放各届黑客松、挑战赛选手提交的参赛作品。目录规范为：

```
hackathon/<年份>/<赛道名>/<队伍或选手>/
```

例如：`hackathon/2026/qaia/team_foo/`。

## 选手提交要求

1. 只在自己的队伍目录内提交内容，目录名使用小写字母、数字、连字符或下划线。
2. 提供 `requirements.txt`，保证评审可以按说明运行你的代码。
3. 不要提交敏感信息（账号、密钥等）与超大文件（单文件尽量不超过 50 MB）。
4. 完整流程与通用要求见仓库根目录的 [CONTRIBUTING.md](../CONTRIBUTING.md)。

如赛事另有专门的提交规则（截止时间、评分标准等），以该赛事目录下的说明为准。
