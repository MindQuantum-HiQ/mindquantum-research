# mq-research-assets

This repository stores large research and internship assets that are moved
out of the main `mindquantum` repository to keep normal clones smaller.

Layout:

- `summer_ospp/<year>/<project-id>/`: archived assets for Open Source
  Promotion Plan projects
- other top-level directories may be added later for paper reproductions or
  other research work

Current imported project:

- `summer_ospp/2024/24c6d0416`

The imported history for `summer_ospp/2024/24c6d0416` was split from the
original `mindquantum` repository so the project-level author history is
retained in this repo.
